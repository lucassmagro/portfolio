# Lucas Santos Magro - UI/UX Engineering & Digital Portfolio 2026

This repository contains the source code for my personal portfolio and project hub. It is engineered with a high-end editorial aesthetic, focusing on clean architecture, performance, and a seamless user experience.

## Overview

The portfolio is designed as an integrated digital space that bridges high-performance front-end engineering with sophisticated visual design. It features a custom internal application for link management along with a showcase of architectural and design projects, all unified through a consistent design language.

## Technical Architecture

The project leverages a modern front-end stack to ensure speed and fluid interaction:
- **Core Engine**: React 18 and Vite for a optimized development and build cycle.
- **Visual Styling**: Tailwind CSS for scalable, utility-first UI development.
- **Motion & Interaction**: Framer Motion for sophisticated animations and Locomotive Scroll for an immersive experience.
- **Internationalization**: Full i18n support for English and Portuguese content.

## Setup and Local Development

To run the project in a local environment, you will need Node.js installed.

1. Install project dependencies:
   ```bash
   npm install
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```

3. Generate a production-ready build:
   ```bash
   npm run build
   ```

## Design Philosophy

The aesthetic approach focuses on editorial clarity and minimalist UI architecture. By prioritizing monochromatic palettes and high-quality typography, the interface achieves a timeless, high-end feel that emphasizes content over decorative elements.
